Git & GitHub

Clonacion de un Repositorio

html-css-js-website-smooth-scroll

Proceso paso a paso: seleccion del repositorio, copia de URL y clonacion mediante Git Bash.

Presentacion
Paso 1 / 3

Seleccion del Repositorio

Se abre GitHub y se busca el repositorio publico html-css-js-website-smooth-scroll de briancodex. Al hacer clic en el botón Code, se despliega un menu con la URL HTTPS de clonacion.

Paso 2 / 3

Ejecucion del Comando git clone

En Git Bash, desde la carpeta C:\desarrollo, se pega la URL copiada y se ejecuta el comando:

git clone https://github.com/briancodex/html-css-js-website-smooth-scroll.git

Git descarga los objetos, resuelve deltas y termina la clonacion exitosamente.

Paso 3 / 3

Carpeta Clonada en el Explorador

Como resultado, la carpeta C:\desarrollo\html-css-js-website-smooth-scroll contiene los archivos del proyecto: .git, .vscode, app.js, index.html, README.md y styles.css.
